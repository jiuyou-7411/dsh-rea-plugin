# REA 工作台（DSH 插件）

本插件把 REA 接进 DSH。上游的 `rea` 技能（`rea.md`、`rea-analysis-optimization.md`、
`rea-tool-design.md`）讲**方法论**；这份文档讲**这个插件自己的东西**——工具怎么分组、
依赖怎么装、面板怎么用。两者内容不重叠。

## 工具分三类，共 220 个

| 前缀 | 数量 | 来源 | 用途 |
|---|---|---|---|
| `mcp__rea__*` | 207 | 上游 MCP 服务 | 完整的逆向工具面 |
| `mobile_*` | 6 | 内置 MobileRE | Android 动态分析：脱壳、Frida、反注入、SO、模拟 |
| 其他（`rea_cli`、`rea_docs`、`rea_unpack` 等） | 7 | 插件本地 | CLI 直调、文档检索、引擎编排 |

**选哪条路**：

- **单点问题，要快** → `rea_cli`。`--format json` + `--filter-output` 只取需要的键，
  一次调用几百字节；MCP 一次返回完整 Evidence 可能几十 KB。
- **多步分析，要保留状态** → MCP 工具。打开的目标在会话里持续存在，后续调用直接接着做。
- **不确定该用哪个** → 先 `rea_docs.search("关键词")`，再 `read` 对应文档的一节。
- **Android 动态** → `mobile_*`，MCP 那边只有静态。

## 依赖：两层，都可一键装

### 分析引擎（4 个）

面板「引擎」页，每张卡有独立按钮：

| 引擎 | 大小 | 解锁什么 |
|---|---|---|
| JADX | 110 MB | Android 反编译 |
| apktool | 4 MB | Android 资源与 smali |
| Frida | npm 包 | 动态插桩 |
| **Ghidra** | **543 MB** | **57 个 native 工具** |

Ghidra 是最大的缺口。没装它时 native 反编译、交叉引用、值流分析全部不可用。

### JDK 21

**装 Ghidra 之前必须先有 JDK 21**，因为 Ghidra 11.2+ 在 Java 17 上拒绝启动。

面板「运行时」区会自动检测：
- 已有 21+ → 显示「就绪，使用系统 Java，无需安装」
- 只有 17 或更低 → 显示「版本过低（17）」，可一键装一份**插件私有 JDK**

私有 JDK 装在 `~/.dsh/rea-jdk/`，通过 `JAVA_HOME` 只对插件启动的子进程生效，
**不改动系统全局设置**——JADX、apktool 继续用原来的 Java 17。

### Python 依赖（7 个，约 271 MB）

面板「移动端工具链」区，每个包一行，可单独装/卸：

```
pyelftools   capstone   keystone-engine   lief
z3-solver    unicorn    frida
```

装之前会**实测 5 个镜像源**（中科大/清华/腾讯云/阿里云/官方），用最快的那个；
失败自动换下一个。选中包会显示它被哪几个脚本依赖，所以一个包报错能立刻定位。

13 个脚本是纯标准库，不装这些也能跑。

## 面板六页

| 页 | 看什么 |
|---|---|
| **总览** | 服务状态、工具总数（220）、常用工具、近期告警 |
| **实时流** | 每一次工具调用：耗时、成败、错误详情（点击展开） |
| **错误** | 按错误类型聚合，`×N` 显示重复次数，附修复建议 |
| **服务状态** | 六项检查逐条说明，异常项带 `→ 具体怎么办` |
| **引擎** | 四个引擎 + JDK + Python 依赖，都可装可卸 |
| **能力** | 八类目标能否分析、每个用哪个引擎、工具分类统计 |

## 出问题时

**工具调用失败** → 「实时流」找到那一条，展开看完整报错。

**native 工具全报 `Ghidra not configured`** → 引擎页装 Ghidra；装之前确认 JDK 21 就绪。

**`mobile_*` 报缺包** → 移动端工具链页，看哪个包是 `✗`，单独装它。

**面板显示「MCP 未连接」** → 总览顶部横幅有具体原因和「重新连接」按钮。
常见原因是首次启动时 `npx rea-agents` 下载失败。

**引擎装了但工具还是不可用** → 重启 DSH。Host 端代码改动必须重启，HMR 只热重载前端。

## 和上游的关系

插件内置的是 `rea-agents@6.7.0`（pin 住的版本）。

- 工具与上游 MCP **完全一致**（207 个，无裁剪）
- 技能来自上游 `.agents/skills`，pin 到 commit `d672cc2`
- 文档索引来自上游 `docs/`，72 篇，pin 到同一 commit
- MobileRE 是独立项目（`index-login/MobileRE-Skill`，MIT），补 Android 动态能力
